# Política de Segurança

## Escopo

Este repositório é um **laboratório educacional** de cibersegurança. Todo o conteúdo foi produzido em máquinas virtuais próprias, em rede host-only, sem exposição à internet e sem alvos reais.

- As técnicas documentadas são para **estudo e testes autorizados**.
- As credenciais citadas são padrão de laboratório (`msfadmin`, `admin`) e não pertencem a sistemas reais.
- O repositório não contém malware, exploits armados ou dados de terceiros.

## Não é um alvo

Não execute os scripts deste repositório contra sistemas de terceiros. Em qualquer ambiente real, é obrigatório ter:

1. autorização escrita do proprietário;
2. escopo e janela de teste definidos;
3. canal de comunicação para incidentes;
4. plano de rollback.

## Reportar um problema

Se você encontrar um problema de segurança **no conteúdo do repositório** (por exemplo, uma credencial real exposta por engano), use o canal privado de [Security Advisories](https://github.com/isaacof/dio-medusa-bruteforce-lab/security/advisories/new) do GitHub.

Evite abrir uma issue pública com detalhes que possam ser explorados.

## Dados sensíveis

- Nenhuma senha pessoal, token, chave privada ou dado de cliente foi utilizado.
- As evidências foram sanitizadas antes da publicação.
- Se você for reutilizar os scripts, revise as wordlists e remova qualquer credencial do seu ambiente.

## Versões e suporte

Este é um projeto de portfólio e aprendizado, sem garantia de suporte contínuo. Contribuições e correções são bem-vindas por pull request.
